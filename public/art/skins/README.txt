Skin drawings (Nov 11). Jade draws these herself. No AI art.

Put each drawing in the skin's folder (space, mycelium, fairy), inside the same
folder it has today, with the same file name and size. For example:
  art/village-path/spot-chat.webp   ->  art/skins/space/village-path/spot-chat.webp
  art/village-build/meadow-open.webp ->  art/skins/space/village-build/meadow-open.webp (the map ground)
  art/globe.webp                    ->  art/skins/space/globe.webp

A drawing that isn't there yet shows today's picture. Restart `npm run dev` after
adding one. The full list is on the design canvas, page "Drawings needed".
